# 演示脚本（约 5–8 分钟）

## 0. 启动

```bat
04-启动\start-all.bat
```

打开 `http://127.0.0.1:5173`；确认模拟银行 `http://127.0.0.1:8080` 也在运行。

## 1. 双因素登录（2 分钟）

1. 进入后台登录页；
2. admin1 / Admin@123456；
3. 首次登录绑定 TOTP，输入 6 位码；
4. 展示管理员后台。

## 2. 业务主流程（2 分钟）

1. 商品列表 → 商品详情/图片；
2. 加入购物车；
3. 创建订单；
4. 发起支付 → 跳转模拟银行 8080/pay → 确认支付 → 支付成功页；
5. 点“返回首页”。

## 3. 安全演示（2 分钟）

1. 未登录访问后台接口 → 401；
2. 普通用户访问管理员接口 → 403；
3. 审计员查看审计事件、导出 CSV；
4. （可选）浏览器开发者工具/抓包展示 `/user/login` 的 SM2/SM4 信封。

## 4. 收尾（1 分钟）

- 说明：1 类漏洞已闭环、4 类已修；性能 20 线程 × 100 循环；
- 指出不足：CBC 无 MAC、隧道仅 /user/login、DAST 未认证态。
